Every shield_decide call for mcp__playwright__* tools was blocked by Frontier Shield (risk_score: 90, reason_codes: ["mcp_server_not_approved"]) — the Playwright MCP server is not on this project's approved-server allowlist. This is a policy decision, not a transient failure, so it was not retried.
